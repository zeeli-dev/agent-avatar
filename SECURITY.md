# Security Policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub security advisories](https://github.com/zeeli-dev/agent-avatar/security/advisories/new). You will get a reply within a few days, and a fix or mitigation plan once the report is confirmed.

The package renders markup from its own source only and does not take HTML from attributes. Reports about injection through `variant`, `state`, `size` or `label` are especially welcome.
